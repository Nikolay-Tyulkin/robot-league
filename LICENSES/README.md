# License texts

- `CC-BY-NC-4.0.txt`: unmodified Creative Commons legal code for Watti, retrieved from https://creativecommons.org/licenses/by-nc/4.0/legalcode.txt.
- Pollen Apache software license files are retained verbatim beside the respective models, together with notices documenting the separate unversioned NC/SA model statement.
- Dependency notices are generated into `public/licenses/THIRD_PARTY.txt` by `npm run notices` and ship with the browser build. They do not replace robot license notices.
